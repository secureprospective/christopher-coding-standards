## Architecture and key code

These are copy-and-merge templates, not independently runnable applications. TypeScript is the base; Astro/Workers/Bun replace/add selective configs. Python, Go and Bash have standalone snippets. Conditional consumer checks in `security.yml` do **not** exercise canonical template directories because no root application configs exist. The three verification workflows only exercise narrow Python/Go/Bash fixtures, mostly through direct CLI calls. Four overlays lack template CI; Go analysistest and Bash Bats are not run by these jobs. Configuration and hook composition must be tested in disposable adopter trees, not by installing into this checkout.

Critical examples: Bash positive integer currently checks only `^[0-9]+$`; Go bloat suppresses linter stderr and uses `grep ... || true`; Bun purity checks only direct AST syntax; Workers typecheck regenerates Env first but excludes all tests. Those are narrower guarantees than several prose claims.
